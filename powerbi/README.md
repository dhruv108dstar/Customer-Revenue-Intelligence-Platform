# Power BI Deliverable

This folder contains the reproducible Power BI handoff for the project. The dashboard should be created from the cleaned analytical tables and SQL views exported from PostgreSQL.

Expected deliverable:

- Customer_Revenue_Intelligence.pbix
- Five pages aligned to the executive, customer, churn, revenue, and data quality requirements

Supporting build artifacts:

- [model_spec.md](model_spec.md): source tables, relationships, and five-page layout
- [dax_measures.dax](dax_measures.dax): core business measures

The `.pbix` file is intentionally not committed because Power BI Desktop is not available in this development environment.
